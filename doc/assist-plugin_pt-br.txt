1. Introdução                                                *Assist-Plugin-intro*

O Assist-Plugin tem como objetivo proporcionar uma experiência mais
amigável para usuários que não estão familiarizados com a interface padrão
do Vim. Para isso, oferece uma linha de status inspirada no Nano, uma
interface de pesquisa aprimorada, com melhor visualização dos resultados,
e atalhos de teclado comumente utilizados. Esses recursos buscam tornar a
navegação e a interação com o editor mais simples e confortáveis para
usuários iniciantes.

==============================================================================
2. Mapeamento (Prefixo de Comandos)                         *Assist-Plugin-mapping*

O plugin utiliza um comando principal para fornecer acesso às suas
funcionalidades. Por padrão, o comando é `:Assist`, que abre o menu do
plugin e apresenta os comandos e recursos disponíveis. A partir desse
menu, o usuário pode acessar as funcionalidades oferecidas.

==============================================================================
3. Comandos                                                  *Assist-Plugin-comandos*

O plugin é dividido em três módulos principais: `CustomizedSearch`,
`StatusLine` e `Shortcut`. Cada módulo oferece funcionalidades específicas
que podem ser ativadas ou desativadas por meio de seus respectivos
comandos. O módulo `Shortcut` é ativado automaticamente ao iniciar o
plugin e permanece ativo até que seja desativado explicitamente.

3.1 Customized Search (Busca Personalizada)                 *assist-comandos-busca*

O comando `:AssistSearch` abre uma janela flutuante que permite pesquisar
palavras no arquivo atual, apresentando os resultados de maneira mais
acessível. Pressionar `/` no modo Normal também ativa a interface de busca
personalizada. O comando `:AssistCloseSearch` fecha a interface de
pesquisa.

3.2 StatusLine (Linha de Status)                             *assist-comandos-status*

O módulo StatusLine oferece uma linha de status personalizada, com
aparência inspirada no Nano. Sua utilização pode ser controlada pelos
seguintes comandos:
- `:AssistStatusLineOn`: Ativa a linha de status personalizada.
- `:AssistStatusLineOff`: Desativa a linha de status personalizada.

3.3 Shortcut (Atalhos)                                      *assist-comandos-atalhos*

O módulo Shortcut disponibiliza atalhos de teclado comumente utilizados,
facilitando a navegação e a interação de usuários iniciantes com o
editor. Ele é ativado automaticamente ao iniciar o plugin e pode ser
controlado pelos seguintes comandos:
- `:AssistShortcutsOn`: Ativa os atalhos de teclado personalizados.
- `:AssistShortcutsOff`: Desativa os atalhos e restaura as configurações
  anteriores do Vim.

Os atalhos disponíveis, suas respectivas funções e as instruções para
ativá-los ou desativá-los podem ser consultados no menu `:Assist`.

==============================================================================
4. Configurações Globais                                      *Assist-Plugin-config*

4.1 Shortcut (Atalhos)                                       *Assist-Plugin-config-shortcut*

O módulo Shortcut modifica algumas opções nativas do Vim para
proporcionar uma experiência de utilização mais familiar. Antes de
realizar essas alterações, o plugin armazena os valores anteriores das
seguintes opções em variáveis locais do script:
- `s:save_keymodel`
- `s:save_selection`
- `s:save_selectmode`
- `s:save_backspace`

Quando os atalhos são desativados por meio do comando
`:AssistShortcutsOff`, os valores originais são restaurados. Esse
mecanismo ajuda a evitar conflitos e comportamentos inesperados ao
retornar às configurações anteriores do Vim. O plugin também utiliza o
script nativo `$VIMRUNTIME/mswin.vim` como parte da implementação dos
atalhos.

4.2 StatusLine (Linha de Status)                             *Assist-Plugin-config-status*

Enquanto o módulo StatusLine estiver ativo, a função `s:DrawNanoPopup()`
impede alterações na opção `cmdheight`. Esse comportamento ajuda a
preservar a organização visual da interface enquanto a linha de status
personalizada estiver habilitada.

Caso seja necessário desativar ou modificar esse comportamento, consulte
a implementação correspondente no diretório `autoload/StatusLine`.

As informações exibidas na linha de status também podem ser
personalizadas. Para modificar o conteúdo apresentado ou sua aparência,
consulte os arquivos `.vim` localizados em `autoload/StatusLine`.

4.3 Customized Search (Busca Personalizada)                 *assist-comandos-config-search*

Enquanto a funcionalidade Customized Search estiver ativa, pressionar
`/` no modo Normal abre a interface de pesquisa personalizada do plugin,
em vez de utilizar o comando de busca padrão do Vim. Quando a janela de
pesquisa estiver aberta no modo Normal, as seguintes teclas podem ser
utilizadas para fechá-la:
- `q`: Fecha a janela de pesquisa.
- `Esc`: Fecha a janela de pesquisa.

O plugin também vincula globalmente o grupo de destaque `PopupSelected`
ao estilo de destaque `WildMenu`. Essa alteração não é revertida ao
fechar a janela de pesquisa e pode afetar outros componentes que
utilizem o grupo `PopupSelected`.
